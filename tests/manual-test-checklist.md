# قائمة اختبارات يدوية - REDFOXIQ TEAM Roadmap

## 1. تحميل الموقع
- [ ] يتم تحميل الصفحة الرئيسية بدون أخطاء JavaScript في Console
- [ ] جميع الملفات الثابتة (CSS/JS) يتم تحميلها بنجاح
- [ ] الإحصائيات تظهر أرقامًا صحيحة

## 2. عرض المسارات والمراحل
- [ ] يظهر مسار RED TEAM مع 6 مراحل
- [ ] يظهر مسار BLUE TEAM مع 6 مراحل
- [ ] عناوين المراحل صحيحة ومطابقة للتحديد

## 3. الكورسات وربطها
- [ ] تظهر الكورسات في المراحل المناسبة
- [ ] روابط الكورسات تفتح في تبويب جديد
- [ ] روابط الكورسات تحتوي على rel="noopener noreferrer"
- [ ] شارة "تم التحقق من الرابط" تظهر للكورسات المتحقق منها
- [ ] لا توجد أزرار شكلية بلا وظيفة

## 4. البحث والفلاتر
- [ ] البحث يعمل أثناء الكتابة
- [ ] البحث يدعم العربية والإنجليزية
- [ ] البحث يتجاهل حالة الأحرف
- [ ] عرض رسالة عدم وجود نتائج عند عدم العثور
- [ ] يمكن مسح البحث

## 5. التفاعل والتقدم
- [ ] يمكن تحديد كورس كمنجز
- [ ] يمكن إضافة/إزالة من المفضلة
- [ ] التقدم يحفظ في localStorage بعد تحديث الصفحة
- [ ] زر تفاصيل الكورس يعمل

## 6. تصميم متجاوب
- [ ] الموقع يعمل على شاشات الهاتف (عرض عمودي)
- [ ] الموقع يعمل على التابلت
- [ ] الموقع يعمل على الكمبيوتر
- [ ] لا يوجد تمرير أفقي غير مقصود
- [ ] النصوص مقروءة بوضوح على جميع الأحجام

## 7. إمكانية الوصول والأداء
- [ ] عناصر التنقل قابلة للوصول بلوحة المفاتيح
- [ ] Focus مرئي على العناصر التفاعلية
- [ ] احترام prefers-reduced-motion
- [ ] لا توجد أخطاء حرجة في Console
